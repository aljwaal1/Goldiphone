# مؤشر الذهب والفضة والبتكوين — الأردن

نسخة مدمجة من تصميمين: عمق التحليل التاريخي (رسم بياني، 5 فترات، أعلى/أدنى) + الاعتماد الكامل على GitHub فقط بدون أي خادم وسيط أو مفتاح API.

## لماذا هذه النسخة دون الأخريين؟
- **الأسعار اللحظية**: مصدر واحد موثوق ومجاني بدون مفتاح (`gold-api.com`)، يدعم CORS فعليًا من المتصفح مباشرة — لا حاجة لـ Cloudflare Worker.
- **تاريخ البتكوين**: محاولة جلب سنة كاملة فعليًا من CoinGecko (مجاني، بدون مفتاح)، وإن تعذّر لأي سبب (تقييد معدل الطلبات مثلًا) يستمر التطبيق بالعمل ويبني التاريخ محليًا تدريجيًا — **بدون أي بيانات تجريبية أو مزيّفة في أي حال**.
- **تاريخ الذهب والفضة**: لا توجد خدمة مجانية موثوقة بدون مفتاح لذلك تُبنى من لقطة سعر تُحفظ يوميًا على جهازك، وتزداد دقة المتوسطات/الرسم كل ما استخدمت التطبيق بانتظام.
- **الأسعار بالأونصة فقط** (بدون تكسير غرام/قيراط) بناءً على طلبك.

## المزايا
- بطاقات ملخص سريعة لكل أصل + تفاصيل عند الضغط.
- رسم بياني بمساحة متدرجة لكل فترة (أسبوع/شهر/3 أشهر/6 أشهر/سنة).
- مؤشرات: مقارنة بالأمس، متوسط 7 و30 يومًا، مدى القرب من القمة/القاع.
- جدول إحصائي كامل لكل الفترات (أعلى/أدنى + الفرق عن السعر الحالي).
- مقارنة أسعارك الخاصة (أكثر من سعر لكل أصل، مع تسمية، وفرق محسوب آليًا).
- وضع ليلي/نهاري.
- سعر الصرف قابل للتعديل اليدوي (افتراضيًا 0.7090 وهو الربط الرسمي).

## النشر
نفس الطريقة المعتادة: ارفع الملفات على مستودع GitHub وفعّل GitHub Pages، ثم أضف الرابط للشاشة الرئيسية من Safari.

## ملاحظة صادقة
لو لاحظت أن قسم "الذهب/الفضة" يأخذ وقتًا ليُظهر متوسطات أو رسمًا بيانيًا كاملًا، هذا متوقع ومقصود — التطبيق لا يلجأ أبدًا لبيانات مُلفّقة لتعبئة الفراغ، بل يصرّح بوضوح "بيانات غير كافية بعد" حتى تتراكم فعليًا.
